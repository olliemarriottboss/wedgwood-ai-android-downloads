# Wedgwood AI Android downloads

Public downloads of the signed Wedgwood AI Android pilot APK. An authorized company account is required to use the application.

Version 0.1.4 is a phone pilot; physical-device acceptance is pending. Android 9 or later is required. Download the APK from Releases, transfer/open it on your Android phone, and use the normal Android installation flow. If device security or company policy blocks installation, contact your administrator rather than bypassing the block.

The private application source and signing key are not published in this repository. The update feed is not yet deployed.
